📱 Daily Calculation App ( Antu Calculator )

A lightweight mobile application built to make day-to-day calculations easier, faster, and more convenient.

The app focuses on a minimal feature set, fast calculations, and easy sharing of calculation results.

🎯 Purpose

The main purpose of this application is to make daily calculations easier.

Instead of using different tools for simple calculations, this app provides commonly needed calculations in one simple and user-friendly application.

The design philosophy is:

⚡ Fast

🎯 Minimal

📱 Easy to use

📤 Easy to share

🧮 Practical for everyday calculations

✨ Features

🧮 Daily calculation tools

⚡ Fast calculation

🎯 Minimal and clean UI

📱 Simple user experience

📤 Easy sharing of calculation results

🚀 Lightweight application

🔄 Application Workflow

Open Application
       ↓
Select Required Calculation
       ↓
Enter Values
       ↓
Calculate
       ↓
View Result
       ↓
Share Result

The workflow is intentionally kept short so users can complete their daily calculations quickly.

🚀 Project Goal

The goal was not to build a complicated calculator with unnecessary features.

Instead, this project focuses on solving a simple everyday problem:

Make daily calculations easier, faster, and easier to share.
